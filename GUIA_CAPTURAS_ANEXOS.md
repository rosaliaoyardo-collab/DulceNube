# Guía de capturas para anexos

Pega capturas auténticas de tu ejecución. No uses imágenes simuladas como evidencia de funcionamiento.

1. **Figura 1. Inicio de sesión de Dulce Nube.** Mostrar la pantalla de acceso.
2. **Figura 2. Catálogo visual de productos.** Mostrar las tarjetas con fotografías, nombres, precios y stock.
3. **Figura 3. Registro de venta.** Mostrar producto seleccionado, cantidad y carrito.
4. **Figura 4. Comprobante de venta.** Mostrar número, detalle y total después de confirmar.
5. **Figura 5. Inventario.** Mostrar tabla de existencias y formulario de alta (rol administrador).
6. **Figura 6. Registro y seguimiento de pedidos.** Mostrar datos del pedido y su estado.
7. **Figura 7. Reportes.** Mostrar indicadores e historial.
8. **Figura 8. Base de datos SQLite en VS Code.** Mostrar el archivo `data/dulcenube.db` y sus tablas.
9. **Figura 9. Pruebas automatizadas.** Mostrar `python -m pytest -v` y su resultado real.
10. **Figura 10. Estructura del proyecto.** Mostrar carpetas `domain`, `application`, `infrastructure`, `ui`, `tests`, `assets` y `data`.

Cada captura debe tener título, número de figura y una explicación breve de qué demuestra.
